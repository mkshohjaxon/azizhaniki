    Xavfli zona

    "Bazadan o'chirish" — sessiya Telegram'da qoladi, keyin qayta import qilish mumkin. "Chiqib ketish" — sessiya Telegram'da ham bekor bo'ladi, qaytarib bo'lmaydi.

    Proxy

    Har akkauntga alohida IP — akkauntlar bir-biriga bog'lanib qolmaydi. Format: socks5://user:pass@host:port, http://host:port yoki host:port:user:pass. Bo'sh — proxysiz.

    Qurilma ma'lumoti

    Telegram sessiyani shu qurilma sifatida ko'radi. Sessiya qaysi qurilmada yaratilgan bo'lsa, o'shani yozing (.json bilan import qilinganda o'zi to'ladi). Tez-tez o'zgartirmang.
